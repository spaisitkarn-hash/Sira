# DMS Training Deck — Introduction & 5 Components

- `DMS_Introduction_5_Components.pptx` — editable deck, 45 slides, 16:9, speaker notes on every slide
- `DMS_Introduction_5_Components.pdf` — PDF export (font-independent)
- `fonts/` — Bai Jamjuree (SIL OFL). Install all four TTFs on the presenting PC, or open the PPTX on a PC that has them and save with *File → Options → Save → Embed fonts*.
- `assets/icons/` — Material Symbols Rounded SVGs (Apache-2.0); icons are embedded in the PPTX as images, so no icon font is needed.

Rebuild: `pip install python-pptx cairosvg pillow lxml && python3 build_deck.py`
